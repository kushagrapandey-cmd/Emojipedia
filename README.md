# Emojipedia

A React dictionary interface that renders emoji names and meanings from a local dataset.

## Implementation

- `mapping-components-practice-forked/src/emojipedia.js` stores the entries.
- `src/components/App.jsx` maps entries into reusable `Entry` components.
- `src/components/Entry.jsx` displays each dictionary item.

Paths under `src/` are relative to `mapping-components-practice-forked/`.

## Run locally

```bash
cd mapping-components-practice-forked
npm install
npm start
```

An early component/props exercise using React 16 and Create React App 3. The legacy toolchain can require a compatible Node environment. There is no backend or account system.
